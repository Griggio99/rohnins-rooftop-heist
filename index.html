CO-OP HEIST

Pick CO-OP in the game menu, create a room and send the 4-letter code. Your friend opens this same site and enters it. You run the same rooftops, see each other as live ghosts, share boss health and share 3 team lives. A downed agent respawns while the team still has lives, so cover each other. Bosses get tougher with two shooters, and the trailing player gets a catch-up boost.

SHARED BOSSES

TEAM LIVES

Three lives for the pair. Spend them wisely: when they run out, you are out.
